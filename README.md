# Accessible Application Portal

A small ASP.NET Core MVC application I built to demonstrate front-end development and accessibility practices. It uses fictional application data.

## Tech Stack

- .NET 10, C#, ASP.NET Core MVC
- Razor Views, Bootstrap 5, JavaScript
- In-memory data

## Features

- View, search, and filter applications
- Add new applications with form validation
- View application details
- Keyboard-friendly navigation, accessible form labels, focus indicators, and validation messages
- Responsive layout

## Run locally

Make sure the .NET 10 SDK is installed.

    dotnet run --project "Accessible Application Portal/Accessible Application Portal.csproj"

Open the localhost URL shown in the terminal.

## Accessibility

The application includes accessibility features based on WCAG 2.1 AA guidelines, including semantic HTML, keyboard navigation, form validation, and screen reader support.

This is a sample project and has not undergone a full accessibility compliance audit.
